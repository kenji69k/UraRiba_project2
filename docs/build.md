# Документация по сборке (Build Documentation)

## 1. Настройки сборки (Build Settings)
*   **Доступные платформы для сборки:** Windows, Linux, Mac (настроены по умолчанию в проекте).
*   **Целевая конфигурация:** Development (без отладочных символов, как требуется в лабораторной).
*   **Целевая папка:** Сборка проекта (Cook & Build) будет производиться в папку "Builds" в корне проекта.
*   **Класс ввода по умолчанию:** EnhancedPlayerInput (система Enhanced Input).

## 2. Пакеты и плагины (Plugins)
В проекте используются стандартные встроенные плагины Unreal Engine 5 (всего 852 встроенных плагина). 
Сторонние плагины отсутствуют.
Среди активных встроенных плагинов можно выделить:
*   Enhanced Input (система ввода).
*   Niagara (система частиц).
*   Blueprints (визуальное скриптование).

## 3. Структура папок проекта
*   **"Content/"**: Содержит основные игровые ассеты. Внутри находятся папки: 
    *   "Audio" (звуки)
    *   "Blueprints" (логика игры)
    *   "Demo" (демо-контент шаблона)
    *   "Fonts" (шрифты)
    *   "GameInstance" (классы GameInstance)
    *   "Maps" (уровни/карты)
    *   "Materials" (материалы)
    *   "Meshes" (3D-модели)
    *   "NiagaraSystems" (системы частиц)
    *   "PhysicalMaterial" (физические материалы)
    *   "Textures" (текстуры)
    *   "Widget" (UI-виджеты)
    *   *Основные типы файлов:* ".uasset" (ассеты) и ".umap" (уровни).
*   **"Config/"**: Содержит конфигурационные файлы (".ini"). Основные файлы: "DefaultEditor.ini", "DefaultEngine.ini", "DefaultGame.ini", "DefaultInput.ini".
*   **"Source/"**: Папка отсутствует, так как проект полностью основан на Blueprints (без C++ кода).

## 4. Размер проекта
*   Приблизительный размер проекта: 87,3 MB.
