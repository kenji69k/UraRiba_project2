# \# Gameplay и физика проекта

# 

# \## 1. Какие физические параметры используются в проекте?

# Гравитация: Стандартная гравитация движка, но для игрока применен Gravity Scale = 1.5.

# Масса: В компоненте движения масса по умолчанию равна 100.0 (в настройках симуляции физики отображается 97.53 кг).

# Скорость и прыжок: Max Walk Speed = 600 см/с, Jump Z Velocity = 600 см/с. Air Control = 0.55.

# Зона смерти: Отключена (установлена на -1048575), игрок не умирает при падении.

# Физические материалы: Присутствует Gem\_PM (для кристаллов/драгоценностей).

# 

# \## 2. Препятствия, враги и бонусы

# Бонусы: Монеты и кристаллы (Coin\_Spawn\_1\_BP, Coin\_Spawn\_2\_BP, Gem\_BP). Loop\_Coin\_Spline\_BP создает монеты вдоль заданной кривой. При столкновении с игроком они начисляют очки.

# Препятствия: 

# \- Движущиеся платформы (Moving\_Platform\_BP) и вращающиеся шестеренки (Rotating\_Cog\_BP).

# \- Отталкивающие платформы (Bounce\_Pad\_BP).

# \- Кольца и челленджи (Ring\_Challenge\_BP).

# 

# \## 3. Какие параметры можно изменить через панель «Детали».

# Для изменения сложности и поведения игры можно настроить:

# Скорость и прыжок: Max Walk Speed (уменьшить, чтобы усложнить), Jump Z Velocity (уменьшить, чтобы сделать прыжки сложнее).

# Гравитацию: Gravity Scale (увеличить для более быстрого падения).

# Свет и пост-обработку: В настройках мира или настройках пост-обработки (для изменения атмосферы).

# Свойства монет: Внутри Blueprint-класса монеты можно настроить количество очков за подбор.
